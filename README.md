# CIFAR10 Image Classification

This project uses ResNet18 and PyTorch to classify images from the CIFAR10 dataset.

## Classes

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

## Training

bash
python train.py
